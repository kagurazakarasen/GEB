# アクロスティック/縦読みジェネレータ（GEB風あとがきにも対応？）
<img width="1123" height="896" alt="Image" src="https://github.com/user-attachments/assets/db12fa31-9cf9-48fd-95a0-65247e61655c" />
左右の縦読みを保ちながら、中央の文章を組版するブラウザーアプリです。本文を手入力するほか、OpenAI互換のChat Completions APIに接続して生成・検証できます。

## 主な機能

- 左右それぞれで縦読みの向き（上から下／下から上）を選べます。既定値は左が上から下、右が下から上です。
- 左右の「使う」チェックで、左のみ・右のみ・両側のいずれかを組版できます。両側を無効にすることはできません。
- 左右両方をチェックして、左を上から下、右を下から上にすると、「ゲーデル・エッシャー・バッハ」のあとがき風の縦読みが作れます。
- 幅は全角文字数で指定します。全角文字は1文字、半角文字は0.5文字として扱います。
- 本文の改行をプレビューに反映します。
- LLM生成後、実際の横行と縦読みの接続を確認し、不自然な場合は修正して再検証します。
- 検証を通過しない場合は、本文を「未検証」と明示して表示します。未検証の文章は完成稿として使用しないでください。
- 組版結果をコピー、またはテキストファイルとして保存できます。
- ローカルLLMのOllamaで作成しましたが、gpt-oss:20bでは力不足で上手く生成できないようです。OpenAIに対応しているのでより強力なLLMを指定することもできます。

## 起動

依存パッケージやビルド手順はありません。`縦読みジェネレータ.html` をブラウザーで開いてください。

1. 左右の縦読みと幅を入力し、それぞれの読む向きと使用する側を選びます。
2. 本文を入力するか、LLMへの依頼文を入力します。
3. 手入力した本文は「組版する」、LLMで作る場合は「LLMで本文を作る」を押します。

## LLM接続

「LLM接続設定」で、接続先APIのURL、モデル名、必要であればAPIキーを設定します。APIはOpenAI互換のChat Completions形式に対応している必要があります。既定値は次のローカル設定です。

| 項目 | 既定値 |
| --- | --- |
| API URL | `http://localhost:11434/v1/chat/completions` |
| モデル | `gpt-oss:20b` |
| APIキー | 不要 |

Ollamaを使う場合は、Ollamaを起動し、`gpt-oss:20b` を取得してから利用してください。別のOpenAI互換APIを使う場合は、接続先のURLとモデル名に変更し、必要なAPIキーを入力します。

## 接続上の注意

- このHTMLからAPIへ直接リクエストします。接続先がブラウザーからのアクセスを許可するCORS設定になっている必要があります。
- APIキーを入力すると、リクエストのAuthorizationヘッダーとして指定した接続先へ送信されます。アプリには保存されません。公開環境や共有端末で秘密のキーを入力しないでください。
- JSON形式の応答に対応していないAPIや、OpenAI互換Chat Completions以外のAPIには接続できない場合があります。
- LLMの検証は文章の横読み・縦読みのつながりを確認するものです。内容の事実性までは保証しません。生成結果は公開前に確認してください。
